# Published reference figures

`published/` contains the complete figure PDFs, including static artwork and
page layouts, for comparison with regenerated panels. The PDFs are reference
artwork; numerical source data are supplied in the figure-linked CSVs.

Generated panel assets are written under `build/figures/`.
`tools/assemble_revision_figures.py` combines panels into complete vector pages
for Figure 4, Extended Data Figure 5, and Extended Data Figure 9.

`published_manifest.json` records the SHA-256 checksum of each reference PDF.
