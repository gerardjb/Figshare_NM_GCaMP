# Precise calcium-to-spike inference using biophysical generative models

This Figshare repository is in support of **"Precise calcium-to-spike inference using biophysical generative models"** from Broussard et al, 2026 *Nature Methods*. It contains the data CSVs, MATLAB plotting functions, Python plotting scripts, shared utilities, and table-generation inputs used to reproduce the manuscript figures, supplementary figures, and tables.

## Publication contents

- `figures/main/figure1` through `figure4` contain the main-figure inputs and plotting code.
- `figures/extended_data/figure1` through `figure9` contain the Extended Data figures.
- `figures/supplementary/figure1` through `figure4` and `note1` through `note2` contain Supplementary Information material.
- `tables/main/table1` and `tables/supplementary/table1` through `table3` contain the tables.
- Figure-linked `source_data` directories contain canonical CSVs and panel-organized workbook views.
- `reference_figures/published` contains the complete reference PDFs and static artwork.
- `shared` contains shared original inputs and plotting utilities.

Original inputs remain available alongside the canonical source-data exports. The CSVs preserve full-resolution data; the supplied workbooks provide readable views of the figure data.
